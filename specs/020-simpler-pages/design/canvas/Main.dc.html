COMMENTARY
How good is the TV? Over 2,133 past innings (2005–2022) it was 22.5 runs off on average. Always guessing the average total was 23.9 runs off, so the run rate barely helps. The TV guesses too low by 14.3 runs on average.
The goal. Beat the TV by at least 3 runs on average, on a season none of the models has seen.
Who does what. A language model picks the clues. Code fits a linear regression to past innings. Code scores it against the TV and the average-total guess.
THE PROBLEM

The TV projection is usually about 22 runs out.

It just multiplies the run rate by 20. Can an agent, left to itself, learn something smarter from 5,209 past innings?

COMMENTARY
What the agent decides
Each idea has four parts: the clues (up to 8 of 19), how many past seasons to learn from, whether recent seasons count more, and which innings to learn from. Code rejects an idea that is off the menu, already tried, or repeats a clue in disguise.
How each idea is scored
Each idea predicts three past seasons it hasn't learned from. Its score is the average miss across the three.
