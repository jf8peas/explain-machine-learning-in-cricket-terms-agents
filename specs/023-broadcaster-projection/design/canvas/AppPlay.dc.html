AN AI AGENT EXPERIMENT

Can an AI agent build a regression model that beats the broadcaster's projected score?

Halfway through a T20 innings, where will it finish? The agent chooses the clues, code does the maths, and it's tested on a season it has never seen.

COMMENTARY
How good is the broadcaster? Over 2,133 past innings (2005–2022) its projection was 22.5 runs off on average. Always guessing the average total was 23.9 runs off, so the run rate barely helps. The broadcaster guesses too low by 14.3 runs on average.
Why a season it never sees? Any model looks good on the data it chose from. 2026 stays locked until the agent has picked its model, then it is used once.
Who does what. A language model picks the clues. Code fits a linear regression to past innings. Code scores it against the broadcaster's projection and the average-total guess.
THE PROBLEM

The broadcaster's projection is usually about 22 runs out.

It just multiplies the run rate by 20. Can an agent, left to itself, learn something smarter from 5,209 past innings?

What makes it an agent?

A language model working in a loop: it looks at the results so far, decides what to try next, and stops when it can't do better. Here the AI makes those decisions in the purple steps; code does everything else.
