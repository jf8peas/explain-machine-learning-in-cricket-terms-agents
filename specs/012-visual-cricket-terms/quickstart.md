# Quickstart: verify the visual "In cricket terms"

1. Backend: run the pytest suite for `apps/linear_regression` (facts, blocks, reply checker, the writing step with the scripted fake model, graph and structure tests).
2. Web: `npm run test` and `npx playwright test` in `apps/linear_regression/web`.
3. Run the app with the fake model and a fast pace. Open The final test: the section shows the verdict with its badge, the drivers chart, the wicket figure, the year strip and the closing sentence, with a label naming the model.
4. Pick the "Unreliable" model: the same section appears with template wording and one line saying why.
5. In the graph, stage 8 shows two steps: the code step and the language-model step. Step back to the first of them: template wording; the second: the model's wording.
6. Light and dark themes, and phone width: no sideways scroll; each chart has a text equivalent.
